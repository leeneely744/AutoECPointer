# AutoECPointer

**AutoECPointer** は **Auto Entry Close Pointer** の略です。

AutoECPointer は、トレード履歴をチャート上に直接可視化するために設計された MetaTrader 4 (MT4) 用のカスタムインジケーターです。エントリーと決済（イグジット）の矢印を自動的に描画し、勝ちトレードと負けトレードを区別することで、トレーダーが過去のパフォーマンスを視覚的に振り返るのに役立ちます。

## 機能

- **履歴の自動可視化**: 口座履歴をスキャンし、トレードをチャート上にプロットします。
- **エントリー＆決済マーカー**: トレードの開始（エントリー）と終了（クローズ）を明確にマークします。
- **損益の区別**: 勝ちトレードと負けトレードを異なる色と矢印コードで区別します。
- **自動更新**: 定期的に新しい履歴の更新をチェックします（デフォルトは5秒ごと）。
- **外観のカスタマイズ**: 矢印コード、色、サイズを完全にカスタマイズ可能です。
- **フィルタリングオプション**: 
  - 現在の通貨ペアのトレードのみ、または全通貨ペアを表示。
  - 期間によるトレードのフィルタリング（遡る日数）。

## インストール

1. `AutoECPointer.mq4` をダウンロードします。
2. MetaTrader 4 ターミナルを開きます。
3. `ファイル` -> `データフォルダを開く` に移動します。
4. `MQL4` -> `Indicators` に移動します。
5. `AutoECPointer.mq4` をこのフォルダにコピーします。
6. MT4 を再起動するか、ナビゲーターパネルの `インディケータ` を右クリックして `更新` を選択します。
7. ナビゲーターから `AutoECPointer` をチャートにドラッグ＆ドロップします。

## パラメータ

| パラメータ | 型 | デフォルト | 説明 |
|-----------|------|---------|-------------|
| **EntryArrowCode** | `int` | `252` | エントリーに使用する矢印コード |
| **EntryBuyColor** | `color` | `clrDodgerBlue` | 買いエントリー矢印の色 |
| **EntrySellColor** | `color` | `clrRed` | 売りエントリー矢印の色 |
| **CloseWinArrowCode** | `int` | `161` | 利確（Win）時の決済矢印コード |
| **CloseWinColor** | `color` | `clrWhite` | 利確（Win）時の決済矢印の色 |
| **CloseLossArrowCode** | `int` | `251` | 損切（Loss）時の決済矢印コード |
| **CloseLossColor** | `color` | `clrYellow` | 損切（Loss）時の決済矢印の色 |
| **OnlyCurrentSymbol** | `bool` | `true` | `true` の場合、現在のチャート通貨ペアのトレードのみを表示します |
| **LookbackDays** | `int` | `365` | 履歴を遡る日数 |
| **UpdateSeconds** | `int` | `5` | 更新間隔（秒） |
| **ArrowSize** | `int` | `5` | 矢印のサイズ（太さ） |
| **PriceOffsetPoints** | `int` | `0` | 矢印を価格から離すオフセットポイント数（重なり防止） |

## 使い方

チャートに適用すると、フィルタ条件に一致する過去のトレードが口座履歴から検索され、自動的に矢印が描画されます。

- **エントリー矢印**: マーケットにエントリーしたポイントを示します。
- **決済（Close）矢印**: ポジションを決済したポイントを示します。
  - **開始 (Entry)**: デフォルトでは 青 (Buy) / 赤 (Sell)
  - **終了 (Close)**: デフォルトでは 白 (Win) / 黄 (Loss)

ローソク足と矢印が重なりすぎる場合は、`PriceOffsetPoints` を調整してください。

## アンインストール

インジケーターを削除するには、チャート上で右クリックし、`表示中のインディケータ` を選択、`AutoECPointer` を選択して `削除` をクリックします。
